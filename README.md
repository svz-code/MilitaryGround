# Военный полигон SvZ_Code

Здесь я провожу всякие эксперементы на разных ЯП.  
Здесь можно встретить абсолютно все что угодно, от простых префиксных сумм до псевдо-exe на Linux!  
Может быть, когда нибудь, какой нибудь из моих эксперементов перестанет быть эксперементом и перерастет в что-то большее, чем эксперемент.  

На данный момент тут два эксперемента:
1. TestPrefSumm.  
   Считает префиксные суммы. По факту первая моя программа на Dlang.
2. KotlinUndCxx.  
   Попытка подружить Kotlin и C++. Успешная, кстати 😇  
   Буду пытаться еще подружить Kotlin и D.
3. Vodka.  
   Интересный эксперемент, где я смог сделать запускаемые exe файлы на Linux!  
   (грубо говоря, запускатор .exe, которые содержат в себе Linux сисколлы)
